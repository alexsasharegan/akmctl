# board

Use it for the state of the work at a glance: items grouped as active, blocked and ready. Read-only.

```
$ akmctl board
== active (0)
== blocked (0)
== ready (1)
261029-atxk	2026-10-29	ready	add json output
```

Files changed: none.

Errors: `unreadable` when the repository cannot be read.
