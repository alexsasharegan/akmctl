# Generate the ADR index as a table Prettier leaves unchanged and compare it byte for byte

## Context

A hand-kept list of decisions drifts and conflicts on merge. A reader with no tools should still be able to open an index. The repository formats Markdown with a pinned Prettier, which would rewrite a generated table if the generator did not already emit its form. (Decision log entries Y3, Y4, Y17.)

## Considered Options

- A hand-written index: drift and merge conflicts.
- A generated index that is not committed: a reader without the tool has nothing.
- A generated, committed index, in the form Prettier leaves unchanged, compared byte for byte by a rule.

## Decision

`akmctl index` writes the index from ADR frontmatter, grouped In force, Proposed and Not in force, padded to Prettier's display width. The file is in `.prettierignore` and rule A4 compares it with the generated bytes. Prettier 3.x is pinned by the repository; `embeddedLanguageFormatting` is off so frontmatter is untouched. There is no `fmt` command.

## Consequences

- A merge conflict in the index is resolved by running `akmctl index`.
- Every Prettier bump is re-tested against the index and width tests.

## Confirmation

Rule A4 in `akmctl check`; `internal/index` tests.
