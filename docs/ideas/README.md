# Ideas

Things you could build on AKM that are not part of AKM. The standard and the tool stay small; this folder shows what the records make possible, so a reader can see past the commands. An idea here is not planned, not promised and not a record: it has no id, `check` does not read it, and nothing depends on it.

An idea page says what it is, what AKM already gives it, what it would still need, and the first small step. When an idea becomes work, file a work item, link it from the page and say so at the top; when it is decided against, leave the page and say why. Pages are Markdown with a short `status`: `idea`, `filed` (a work item exists) or `set aside`.
