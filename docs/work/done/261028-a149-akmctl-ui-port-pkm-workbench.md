# Port the pkm-workbench UI onto the akmctl API

## Goal

`akmctl ui` serves a thin Kanban page (milestone 6 of [[261027-r3hh-repo-records-go-tool]]). The vault's `pkm-workbench` (`~/github.com/alexsasharegan/pkm-workbench`, binary `pkm-wb`) has a much better UI: keyboard-driven board with vim keys, transactional moves with undo, a wizard for gated moves and a review page that shows the exact diff, capture with a live slug preview, a command palette with task search, a Tables view, watch mode that streams outside changes to open boards with animation, open-in-Obsidian, and the "Quiet paper" theme (tokens in `theme.css`, light and dark, Monaspace fonts). Its limit is the data model: it reads only the vault's `9 pkm/tasks/` with the vault's own fields and has no ids, parents, lists, priorities or JSON API.

Bring that UI over to the `akmctl` API (the specification of the operations is [[akm-api-spec]]) and retire the `pkm-wb` server, so one workbench serves every AKM repository. The decision to fold `pkm-workbench` into this project is recorded in [[261027-r3hh-repo-records-go-tool]] and [[261025-r0ye-pkm-workbench-a-local-server]].

Done when:

- `akmctl ui` shows the board and tables for an AKM repository with the interaction, style, moves, capture and live updates listed above.
- The same flows work on the dogfood layout of the `akmctl` repository ([[261028-eqwq-akmctl-dogfood-akm-layout]]) and on the API fixtures.
- Tests: the existing server tests, plus tests for the new routes; the page is exercised in the browser by an agent and the findings are in the Log.
- The `pkm-workbench` repository has a note saying the UI moved, and its server is retired or reduced to what is vault-specific, with the decision logged.

## Scope

- Style: the tokens, the "Quiet paper" theme, the fonts (check the licences allow embedding), light and dark.
- Interaction: the keyboard model, the command palette and search, the Board and Tables views, the hint bar, key help.
- Moves: safe moves write at once with undo; gated moves go through a wizard and a review of the exact change; the write is guarded by the record's `etag` (the API's `If-Match`), which replaces the SHA-256 check.
- Capture: new `raw` item with a live slug preview, using `new`.
- The AKM model: ids, `parent` and children, `blocked_by` (ids and free text), `priority`, `kind`, `summary`, ADR list and the check view, the claims extension when the manifest enables it.
- Live board: changes made outside the app (an agent, an editor, Obsidian) appear on open boards.
- Open a record in Obsidian where the repository is a vault (needs the vault name; a setting).

## Decisions to make first

- Server-rendered pages (as `pkm-wb`) or a client that calls the JSON API (as the current `akmctl ui`). The API is the contract, so a client that uses it is the cleaner fit; it also leaves the HTTP binding as the only server surface.
- Live updates: the API spec says "no event stream in 1.0". Add a Server-Sent Events route in a MINOR API version, or poll `GET /records?since=`.
- Token hand-off: the URL fragment (now) or a one-time `?t=` that becomes an HttpOnly cookie (as `pkm-wb`).
- Whether the single-server-reuse state file and auto-open of the browser come over (`pkm-wb` has both; `akmctl ui --open` has the second).
- What remains vault-specific (the task-lifecycle wizard rules: outcome, ADR check) and whether that becomes a repository setting or stays in `pkm-wb` until the vault migrates.

## Outcome

`akmctl ui` is the workbench for an AKM repository: Quiet paper style and bundled fonts, vim keys, palette and search, board and tables, moves with undo, wizard and exact-diff review guarded by `etag`, capture, live polling, claims, open in Obsidian. Built across branches `ui-server`, `ui-shell`, `ui-live`, `ui-moves`, `ui-finish` (on main at 387aaea) and `ui-final` (3 commits, 65a55e0, 2abb050, 514d0f9, pending merge). Driven by hand on a copy of the akmctl repository; open loose ends are work items in `akmctl/docs/work/` (card claim holder, field editing, review diff order, undo depth, move rollback, `7zcp`). The vault keeps `pkm-wb` frozen until its migration.
