# Dropped fizzle and close streaks

## Goal

Beside the confetti cannon on done (4n0v spike): a quiet fizzle when an item is dropped, and a streak (a count that builds when several items close in a row and resets after a pause). Opt-in with the confetti switch; nothing plays under prefers-reduced-motion.

Done when:

- [ ] dropped plays a short fizzle and done keeps the cannon
- [ ] three closes within a minute show a count and a larger burst
- [ ] the streak is presentation only: nothing is written to a record
